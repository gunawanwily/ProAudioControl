PRO-AUDIO-CONTROL — UNIVERSAL INSTALLABLE PWA
Version: V15 Clean Drag & Drop / Scrollbar Fix

TARGET DEVICES
- Windows PC / laptop: Chrome or Edge
- Android phone / tablet: Chrome or compatible Chromium browser
- iPhone / iPad: Safari
- Landscape and portrait are supported

IMPORTANT
A PWA normally needs to be opened from HTTPS (or localhost). Opening index.html directly
with file:// is not the same as installing the PWA.

INSTALL
1. Upload this folder to an HTTPS web host, or run it from a local HTTPS/localhost server.
2. Windows: open the site in Chrome/Edge -> Install app / Add to desktop.
3. Android: open in Chrome -> Add to Home screen / Install app.
4. iPhone/iPad: open in Safari -> Share -> Add to Home Screen.
5. Tablet: use the same Android/iPad instructions; orientation is set to any.

AUDIO
Local audio files are loaded from the device using the browser's file picker or drag-and-drop.
The browser must support the selected codec. MP3/WAV are generally the safest choices.

NOT A NATIVE APK/EXE/IPA
This package is a cross-platform PWA. It provides one installable app experience across
Windows, Android, iPhone/iPad, phones and tablets without changing the dashboard UI.
A signed native Android APK, Windows EXE/MSIX, or iOS IPA requires platform-specific
build/signing tooling and, for iOS, Apple provisioning.
