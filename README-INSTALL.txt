PRO-AUDIO-CONTROL V19 — SHOW BANK / OPERATOR WORKFLOW

V19 keeps the supplied PRO AUDIO CONTROL app icon and the existing 15-pad audio engine, then adds operator-focused workflow tools.

VISIBLE CHANGES
- The previous SHORTCUT / QUICK TRIGGER CARD has been removed from the dashboard.
- Tablet/phone users continue to operate directly by touching the pads.
- Laptop/desktop users can trigger pads from the keyboard only: 1–9 = Pads 1–9, 0 = Pad 10, Q/W/E/R/T = Pads 11–15.
- Keyboard shortcuts do not fire while typing in inputs, text areas, selects, buttons, or editable notes.
- SHOW BANK A/B/C: three separate show layouts.
- SAVE / RECALL: saves the pad setup and local audio files in browser IndexedDB, so a saved bank can be recalled in the same installed app/browser.
- UNDO: restores the state captured immediately before the latest bank recall.
- TRIGGER: INSTANT or HOLD/MOMENTARY. INSTANT is the default. HOLD starts while the pad/keyboard is held and fades out on release.
- PAD EDIT / PAD LOCK: prevents accidental changes to loaded material, name, volume and loop settings while playback controls remain usable.
- LAST PLAYED: shows the latest triggered pad.
- Countdown warning: the pad timecode changes state during the final 10 seconds and final 3 seconds.
- Existing crossfade/fade behavior is retained.

AUDIO / CUE NOTE
The existing CUE button remains available. Separate MAIN vs headphone/PFL/RFL hardware routing is browser/device dependent; this V19 does not claim to create an isolated physical output when the browser cannot expose that routing.

INSTALL
Windows: Chrome/Edge -> Install app.
Android: Chrome -> Install app / Add to Home Screen.
iPhone/iPad: Safari -> Share -> Add to Home Screen.
Portrait and landscape are supported. PWA installation requires HTTPS or localhost.

IMPORTANT
Browser storage is local to the installed app/browser profile. If browser site data is cleared, saved banks may also be cleared.
